# LG developer installation
Install official webOS CLI and enable Developer Mode on the TV. Run bash package-dev.sh to generate the IPK. Configure the TV using ares-setup-device and obtain its developer key with ares-novacom --device TV --getkey (replace TV with your configured device name). Verify the device identity before trusting it. Install with ares-install --device TV dist/<package>.ipk and launch with ares-launch --device TV com.dichgame.subtitles. These commands require a computer and have not been tested on hardware. This receiver is fullscreen, not a verified HDMI overlay. Mobile installation is not implemented.
