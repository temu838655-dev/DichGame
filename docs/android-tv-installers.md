# Android phone → TV installers

- Google/Android TV: production phone APK bundles the same signed TV APK produced in CI. Temporary local URL expires after ten minutes; the user downloads and confirms installation on TV. No ADB or silent installation required.
- LG: enable Developer Mode and Key Server; enter private IP and six-character passphrase; approve SSH fingerprint; install bundled IPK and launch. Fullscreen app does not overlay HDMI.
- Samsung: in Apps enable Developer Mode (12345), set Host PC IP to the Android phone's current LAN IP, restart TV. Import a DichGameTV.Receiver WGT already signed for that TV and explicitly confirm installation. SDB client transfers and invokes TV-specific installation; requires the TV installation completion message, then checks launch separately. Unsupported authentication, protocol variants or certificates fail rather than reporting success. Certificate creation/signing on mobile is NOT implemented. No external installer or catalog required for transfer.
- Physical TV compatibility is unverified. Use trusted LAN only. See Samsung official CLI/certificate docs and SDB protocol reference: https://developer.samsung.com/smarttv/develop/getting-started/using-sdk/command-line-interface.html ; https://github.com/RoboA-PLAYZ/blue-penny/blob/main/docs/tizen-sdb-protocol.md .
